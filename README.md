# Blackcat Light OS (V3)

A protocol-agnostic microkernel ChatOps OS engineered for high-frequency short interactions (Apple Watch & Smart Glasses friendly).

## Core Philosophy: Quick Gateway

Except for the Calculator and Game Hub, all tools operate on a **One-shot → IDLE** mechanism. It acts as an instant data sanitizer and cross-device buffer, resolving the pain points of manual text copying.
